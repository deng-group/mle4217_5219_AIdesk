The key task is to develop an AI Learning Agent: create a centralized, intelligent agent powered by a fine-tuned LLM that serves as the primary educational companion for the course. Innovate the User Interface: Design and build an intuitive, node-based visual website (the "Nexus") that encourages non-linear exploration and discovery of course content. Enhance Conceptual Understanding: Empower students to instantly get clear, context-aware explanations and see the hidden connections between different topics. Build Foundational Infrastructure: Procure and configure a high-performance workstation to enable local, cutting-edge development and fine-tuning of open-source LLMs for educational purposes.
The course content will be presented as an interactive graph, not a list of topics. Nodes like "Crystal Structures," "Materials Project," "Molecular Dynamics," and "MACE Potentials" will be visually linked. This structure allows students to see the curriculum's architecture and navigate based on their curiosity. 

 

The AI Learning Agent: Clicking on any node will activate the AI agent. This is not a generic chatbot; it is an open-source Large Language Model (e.g., Gemma 3, or Mixtral) specifically fine-tuned on my lecture notes, textbooks, and key research papers. Its purpose is to: (i) Explain Concepts: Provide clear, accurate explanations of the selected node (e.g., "What is a convex hull and why is it important?"). (ii) Bridge Topics: Explain the relationships between connected nodes (e.g., "How is data from the Materials Project node used to train a MACE Potential?"). (iii) Provide Interactive Examples: Link to small, embedded code snippets, visualizations, or external tools relevant to the node, making learning more interactive. 

 

The experience and knowledge from this project are transferable and will also benefit other AI-related courses in our department, such as: MLE5215 Atomistic Modelling of Molecules and Materials, MLE5217 Foundations of Machine Learning for Materials Science, MLE3112 Machine Learning Approaches in Materials Laboratory, and the under-developing AI for Materials course. 

 

Success will be defined by the platform's ability to improve students' integrated understanding of the course material. Particularly, following metrics will be measured: 

User Analytics: Track student navigation paths through the Nexus. We will assess the diversity of topics explored and the frequency of interaction with the AI agent.  

Performance: Compare student scores on exam questions that require connecting multiple concepts against data from previous years.  

Student Surveys: Measure student perceptions of conceptual clarity, ease of navigation, and the overall usefulness of the Nexus as a learning tool.  

Focus Groups: Conduct sessions to gather in-depth feedback on the quality of the AI agent's explanations and the intuitiveness of the node-based interface.
